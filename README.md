# WhatsApp-бот для учеников

Бот сам пишет ученикам по расписанию (по умолчанию Пн/Ср/Пт в 19:00 по Бишкеку)
и пересылает вам их ответы в WhatsApp.

## Что понадобится
- Отдельный номер телефона для бота. Этот номер **нельзя** одновременно использовать
  в обычном WhatsApp.
- Аккаунт Facebook и бесплатный аккаунт Meta Business.
- Хостинг, где бот будет работать круглосуточно (например, Render или любой VPS).

## Шаг 1. Подключите WhatsApp в Meta
1. Откройте https://developers.facebook.com → «Мои приложения» → «Создать приложение» → тип **Business**.
2. Добавьте продукт **WhatsApp** и пройдите настройку (Getting Started).
3. Добавьте свой номер для бота и подтвердите его по SMS.
4. Скопируйте **Phone number ID**.
5. Создайте **постоянный токен**: Business Settings → System Users → создать пользователя →
   Generate token с правами `business_management`, `whatsapp_business_messaging` и `whatsapp_business_management`.
6. Добавьте способ оплаты в WhatsApp Manager: сообщения платные, обычно это центы за штуку.

## Шаг 2. Создайте 2 шаблона сообщений
Откройте WhatsApp Manager → Message Templates → Create. Категория **Utility**.

**Шаблон `okuu_tekshiruu`** (для учеников), язык **Kyrgyz (ky_KG)**:
```
Салам, {{1}}! 👋 Окуу кандай болуп жатат? Бул жумада эмне жакшы болду, эмне кыйын болду? Ушул жерге жооп жаз, баарын окуйм.
```

**Шаблон `otvet_uchenika`** (пересылка вам), язык **Russian**:
```
Ответ от ученика {{1}}: {{2}}
```

Проверка обычно занимает от нескольких минут до суток.

## Шаг 3. Заполните список учеников
Файл `students.csv`: имя и номер в международном формате без плюса.
```
name,phone
Айбек,996555111111
```

## Шаг 4. Запустите бота
```bash
pip install -r requirements.txt
cp .env.example .env      # и заполните
gunicorn bot:app --workers 1 --bind 0.0.0.0:8000
```
⚠️ Запускайте только с `--workers 1`. Иначе ученики будут получать рассылку несколько раз.

## Шаг 5. Подключите webhook
В Meta: WhatsApp → Configuration → Webhook:
- Callback URL: `https://ваш-адрес/webhook`
- Verify token: то же, что `VERIFY_TOKEN` в `.env`
- Подпишитесь на поле **messages**.

## Как пользоваться
- Рассылка уходит сама по расписанию.
- Ответ ученика приходит вам: «📩 Айбек (+996...): текст».
- Чтобы отправить рассылку прямо сейчас, напишите боту `/рассылка` со своего номера.
- Новый ученик: добавьте строку в `students.csv`, перезапускать бота не нужно.

## Важно
- Первое сообщение от бота каждому человеку должно быть утверждённым шаблоном. Это правило WhatsApp.
- Предупредите учеников, что будет писать этот номер, и попросите сохранить его в контакты.
  Если много людей заблокируют номер или пожалуются, Meta ограничит бота.
- Новый номер сначала может писать ограниченному числу людей в сутки. Лимит растёт сам по мере использования.
